# 反过来：从谱到分子式

用 M+1 / M 估碳数：碳数上限 = I(M+1) / (I(M) × 1.1%)。两个例子是氟甲烷 CH3F（M = 34）和甲醛 CH2O（M = 30）。

- **数据**：两张峰表抄自课件"Now the opposite!"一页。
- **推断部分**：各峰的离子归属、同质量候选（H2S、PH3、C2H6、NO）的同位素比值估算、自化学电离的反应式 CH2O+• + CH2O → CH2OH+ + HCO•。课件只写了"Self CI"两个词。
- **用到的丰度**：13C 1.1%，2H 0.015%，15N 0.37%，17O 0.04%，18O 0.20%，33S 0.8%，34S 4.5%（相对最轻同位素）。
- **交互**：碳数小算盘可填任意 M、M+1 强度；两张谱各自可选峰和放大 10 倍。
