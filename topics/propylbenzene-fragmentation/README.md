# 丙苯是怎么碎的

丙苯（C9H12，M = 120）的电子轰击质谱。讲苄基断裂（M − 29 → m/z 91 基峰）、m/z 92 的两个来源（91 的 13C 同位素峰与麦氏型重排离子 C7H8+•）、以及 91 → 65 → 39、77 → 51 的连续丢乙炔。

- **数据**：峰强度是从课件图上读出的近似值（原图改编自 SDBS，标注 © Dr Phil Brown 2020），只收了标注过的峰和几根较明显的小峰，不能用于定量。
- **推断部分**：离子归属和机理按常见教科书说法给出；92 中同位素与重排各占多少，是用"7 × 1.1% ≈ 7.7"对读图值约 11 做的估算。
- **交互**：点峰或下方的数字选峰；朱色实线是来源，灰色虚线是去向；"放大弱峰"把纵轴放大 5 倍。
