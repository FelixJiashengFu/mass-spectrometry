# 二苯甲酮：四根峰，一条链

二苯甲酮（C13H10O，M = 182）的电子轰击质谱。主链 182 → 105（−C6H5•）→ 77（−CO）→ 51（−C2H2）；另有 M − CO → 154 → 152 和 M − H → 181 两条小路。

- **数据**：峰表抄自课件"Any ideas for this spectrum?"一页，结构由课件给出。
- **推断部分**：碎片归属、"不知道答案时怎么猜"的五步、不饱和度计算。75.5 和 76.5 解释为质量 151、153 的双电荷离子；m/z 91（强度 0.1）可能是双电荷分子离子，这一条只是推测。181、165 的环状结构是文献中常见的归属，页面上已注明"一般认为"。
- **交互**：碳数小算盘预填了 182 / 183 的强度；"放大弱峰"放大 10 倍后可看清 150 附近的一簇和半整数峰。
